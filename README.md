# ThisDay — Этот день в истории

Android-приложение для знакомства с историческими событиями,
людьми и праздниками выбранного дня.

Данные загружаются из русскоязычной Википедии. Интерфейс написан
на Kotlin с использованием Jetpack Compose и Material 3.

## Возможности

- Просмотр событий, родившихся людей и праздников.
- Переключение между соседними днями.
- Выбор даты через календарь и возврат к сегодняшнему дню.
- Главная карточка события и хронологический список.
- Экран подробностей события со связанными статьями.
- Открытие статей Википедии в браузере.
- Загрузка изображений с заглушкой при их отсутствии или ошибке.
- Отправка текста события через системное меню «Поделиться».
- Состояния загрузки, ошибки и пустых списков.
- Повторная загрузка после ошибки.
- Светлая и тёмная темы.

## Архитектура

Проект разделён на слои:

- `data` — сетевые запросы, DTO, преобразование данных и реализация репозитория.
- `domain` — модели приложения и интерфейс репозитория.
- `presentation` — экраны, компоненты, тема и управление состоянием.
- `di` — ручное создание зависимостей через AppContainer.

Поток данных:

Wikipedia API → Repository → ViewModel → StateFlow → Compose UI

Действия пользователя передаются во ViewModel через TodayCommand.
Интерфейс отображает состояние TodayState.

Просмотр подробностей управляется выбранным событием в состоянии экрана.

## Запуск проекта

1. Клонируйте репозиторий.
2. Откройте корневую папку проекта в Android Studio.
3. Установите Android SDK, указанный в конфигурации модуля app.
4. Выполните Gradle Sync.
5. Запустите приложение на устройстве или эмуляторе с Android 9.0
   (API 28) или новее.

Отдельный API-ключ не требуется.

Версии библиотек находятся в `gradle/libs.versions.toml`.
Версии Android SDK указаны в `app/build.gradle.kts`.

## Работа с данными

Приложение запрашивает данные по месяцу и дню:

GET https://ru.wikipedia.org/api/rest_v1/feed/onthisday/all/{MM}/{DD}

События, родившиеся люди и праздники загружаются одним запросом.
Переключение категории использует уже полученные данные.

У события может быть несколько связанных статей.
Наличие изображения зависит от данных выбранной статьи.

## Источники

Тексты и ссылки предоставлены Википедией.
Изображения загружаются по адресам, указанным в ответах API.

Права на тексты и изображения принадлежат соответствующим авторам.
Условия использования материалов следует проверять на страницах
Википедии и файлов Wikimedia Commons.

ThisDay — независимый учебный проект, неофициальное приложение.
